# Valueztech Maximo Developer: documentation

Public documentation and issue tracker for **[Valueztech Maximo Developer](https://marketplace.visualstudio.com/items?itemName=valueztech.maximo-developer)**, the VS Code extension that pulls IBM Maximo / MAS automation scripts (foldered by launch point) and Maximo Mobile app source into your workspace, and shows every server change as a diff before it touches your files.

[![Visual Studio Marketplace](https://img.shields.io/visual-studio-marketplace/v/valueztech.maximo-developer?label=VS%20Marketplace&color=1e5a8e)](https://marketplace.visualstudio.com/items?itemName=valueztech.maximo-developer)
[![License: MIT](https://img.shields.io/badge/license-MIT-e8b443)](LICENSE)
